1. Document Ready
- jQuery: $(document).ready(function() {})
- JavaScript: document.addEventListener("DOMContentLoaded", function() {})
2. Get Input Value
- jQuery: $("#name").val()
- JavaScript: document.querySelector("#name").value
3. Change Text
- jQuery: $("#message").text("Hello")
- JavaScript: document.querySelector("#message").textContent = "Hello"
4. Submit Event
- jQuery: $("#feedback-form").on("submit", handler)
- JavaScript: document.querySelector("#feedback-form").addEventListener("submit", handler)
5. Hide Element
- jQuery: $("#box").hide()
- JavaScript: document.querySelector("#box").hidden = true
6. Show Element
- jQuery: $("#box").show()
- JavaScript: document.querySelector("#box").hidden = false
